skilj

A Rust library for event-sourced applications on Postgres. Define events and commands, and skilj handles storage, consistency checks, and GraphQL and REST APIs.

  • Dynamic Consistency Boundaries: a command is decided against only the events it shares tags with, not a whole aggregate.
  • Per-person encryption and blind tags, so personal data can be forgotten.
  • Projections, snapshots, schedules, and bridges to Kafka, AMQP, NATS and Temporal.

Try it with only Rust installed, no database to set up:

cargo install cargo-generate
cargo generate --git https://github.com/gklijs/SkilJ.git \
  templates/skilj-template --name my-wallet
cd my-wallet && cargo run --bin server
